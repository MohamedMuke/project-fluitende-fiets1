
Fluitende Fietser

Over het project
Fluitende Fietser is een website voor een fietsenwinkel.
Bezoekers kunnen fietsen bekijken, informatie over de winkel lezen
en contact opnemen.

Pagina's
- **Home:** welkomstgedeelte en fotocarrousel.
- **Fietsen:** overzicht van beschikbare fietsen.
- **Verhuur:** informatie over fietsverhuur.
- **Over ons:** informatie over de fietsenwinkel.
- **Contact:** contactgegevens en contactformulier.
- **Winkelmandje:** fietsen selecteren en de totaalprijs berekenen.
- **Privacy:** privacyverklaring.
- **Algemene voorwaarden:** de algemene voorwaarden van de website.

Gebruikte technieken
- HTML voor de structuur van de website.
- CSS voor de vormgeving en responsive layout.
- JavaScript voor de interactieve onderdelen.

Functionaliteiten
- Fotocarrousel op de homepagina.
- Klok en melding over de openingstijden.
- Navigatiemenu op de pagina's.
- Winkelmandje met prijsberekening.
- Fietsen verwijderen uit het winkelmandje.
- Responsive ontwerp voor verschillende schermformaten.
- Favicon in het browsertabblad.

Bestanden
- `index.html`: homepagina.
- `fietsen.html`: fietsenoverzicht.
- `verhuur.html`: verhuurpagina.
- `over-ons.html`: informatie over de winkel.
- `contact.html`: contactpagina.
- `winkelmandje.html`: winkelmandje.
- `privacy.html`: privacyverklaring.
- `algemene-voorwaarden.html`: algemene voorwaarden.
- `stylesheet.css`: CSS voor de website.
- `script.js`: JavaScript voor interactieve onderdelen.
- `images/`: afbeeldingen en logo.

Website starten
Open `index.html` in een browser om de website te bekijken.
Je kunt de website ook via Visual Studio Code met Live Server starten.

Let op
De website is een schoolproject. De afrekenfunctie is een demo
en verwerkt geen echte betalingen.
